AgendaBot

Esta es una barbería de prueba en Santo Domingo atendida por un agente con IA. Escríbele como le escribirías por WhatsApp: pregunta precios, pide un turno o cancélalo. En el ticket del backend aparece lo que hizo el servidor con cada mensaje.

Las respuestas las genera una IA (Gemini, de Google), que recibe lo que escribes. Los mensajes se guardan hasta 90 días. No pongas datos reales: usa un nombre inventado. Cómo se tratan los datos.

Ticket del backend

Cada mensaje imprime las herramientas que usó el agente y lo que le respondió el servidor.

— sin movimientos —

propose_appointment no agenda nada: solo guarda una propuesta y el agente te pregunta si confirmas.

confirm_pending solo funciona en el mensaje siguiente al tuyo. Si el modelo intenta confirmar sin que hayas respondido, el servidor lo rechaza y sale en rojo.
